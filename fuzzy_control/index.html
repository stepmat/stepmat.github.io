Fuzzy Logic Simulator

This program simulates a fuzzy logic controller for an air conditioner. It takes two inputs (Temperature and Humidity) and works out the AC's target temperature.

1. Fuzzification — Temperature

Set membership degree of the input temperature in each linguistic term (Cold, Warm and Hot).

0 °C 40 °C

2. Fuzzification — Humidity

Set membership degree of the input humidity in each linguistic term (Dry, Comfortable and Humid).

0 % 100 %

3. Rule Evaluation

Each combination of Temperature and Humidity has a corresponding rule for the desired air-con mode (Cooling or Heating). Each rule outputs its membership in this desired mode, equal to the minimum (AND) of its temperature and humidity set membership degrees.

Total membership per mode (Cooling and Heating)

Each total is the maximum (OR) output value among the rules pointing to that mode.

4. Aggregation & Defuzzification

The Cooling/Heating total membership values are reduced to a single air-con target temperature via the centroid method.
