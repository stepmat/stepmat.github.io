About

  • Initial Chance — probability that each pixel starts alive (rock) when a new world is generated.
  • Number of Steps — how many generations to run automatically right after randomising.
  • Birth Limit — a dead pixel becomes alive if it has more alive neighbours than this.
  • Death Limit — an alive pixel dies if it has fewer alive neighbours than this.
