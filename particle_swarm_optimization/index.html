The Problem: Finding the Highest Point

Imagine a flock of birds flying over an area, trying to find its highest point. Each bird can move freely, but can only sense the height of the ground directly beneath it — it has no map of the surrounding terrain. Flying blind like this, how can the flock efficiently search the whole area and converge on the highest point?

The Algorithm: Particle Swarm Optimization

Each bird's current position, P = (x1, x2), represents a possible solution to the problem — similar to a chromosome in a genetic algorithm, but suited to continuous-value domains. The quality of that position is measured with a fitness function f(x1, x2), which in this example simply returns the height of the ground at that position.

At any given time, each bird tracks two things: its position P and its velocity v (the direction and speed it's currently moving in). Each bird also remembers the best position it has personally found so far — its Pbest (personal best) — as well as the best position found by the whole flock, the Gbest (global best).

How one iteration works

  1. Every bird starts at a random position with a random initial velocity.
  2. Each bird measures the height at its current position using the fitness function.
  3. If this is the best height that bird has personally found, it updates its Pbest. If it's the best found by any bird so far, it updates the flock's Gbest.
  4. Each bird updates its velocity, pulling it toward its own Pbest and toward the flock's Gbest.
  5. Each bird moves to its new position by applying its updated velocity.
  6. The process repeats for the next iteration.

The velocity and position update formulas

Each time step, every bird updates its position and velocity using the following formulas:

v = v + c1 ( Pbest − P ) + c2 ( Gbest − P )
P = P + v

The velocity update pulls the bird toward the best position it has personally found (Pbest) and the best position the whole flock has found (Gbest). The bird then moves in the direction of its velocity. The size of each pull is controlled by the personal weight (c1) and global weight (c2) — raising one relative to the other makes birds rely more on their own experience or more on the flock's, respectively.
